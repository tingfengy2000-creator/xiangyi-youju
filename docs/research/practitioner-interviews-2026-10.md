# 从业者访谈结论（2026 年 10 月）

| 项目 | 内容 |
| --- | --- |
| 时间 | 2026-10-08 至 10-10 |
| 人数 | 3 位：1 位非遗手艺人，2 位文旅办负责人 |
| 形式 | 观看 3 分钟演示视频后，由队员按访谈提纲提问并填写反馈表 |
| 匿名 | 只用对方同意的身份写法：“某非遗土陶手艺人”“文旅办主任”。仓库不记姓名、单位、城市和联系方式；原始反馈表留在队员本地 |
| 引用 | 三位都亲口同意匿名引用；下文原话一字未改 |

**样本边界**：只有 3 人，都是看视频，没有上手操作。下文只说“3 位受访者中有几位提到”，不换算成百分比，也不代表行业普遍情况。三位都没有谈具体金额，所以本文不出现任何收入或成本数字。

## 1. 他们实际怎么做

| 问题 | 手艺人 | 文旅办主任 A | 文旅办主任 B |
| --- | --- | --- | --- |
| 一年组织几场 | 3–4 次 | 非遗类至少十余场 | 每年近 20 场，全区每年上百场 |
| 单场人数 / 时长 | 人数不固定，半天到两天 | 五六十人没问题，体验多在半小时内 | 10–20、30–50 乃至上百人都有，半天到一天 |
| 讲解词从哪来 | 没有讲解词，按游客提问回答 | 传承人自己形成，没有核对这一步 | 传承人自己提供 |
| 遇到说法不一 | 无 | 会有，比如游客问移民从哪里迁来；不懂就如实告诉游客 | 会有，不当场判对错；查证后再告诉游客 |
| 活动为什么会变 | 主要是搬运制作机器 | 事先会做 2–3 版方案，变了就群发给各队长和主办方 | 一般不会临时变，变是因为对象不同：青少年、学生、老年人、专业成年人、游客 |
| 作品和授权 | 可以发到网上给全国观众看 | 题材多是生肖、山水，不存在侵权问题 | 没有去管这个 |
| 付费倾向 | 不确定 | 按场次 | 政府层面不好说 |

## 2. 三幕的打分（1–5 分）

| 幕 | 手艺人 | 文旅办主任 A | 文旅办主任 B |
| --- | --- | --- | --- |
| 第一幕 · 讲对 | 3 分：对自己不会讲错，但对朝代、年代模糊的地方有帮助 | 4 分：传承人多的项目，历史性的说法容易有出入，很有帮助 | 5 分 |
| 第二幕 · 排好（旧版：临时改需求） | 3 分：这些工作由政府做，对手艺人不透明 | 3 分：政府会提前做好 2–3 版方案 | 3 分：不需要临时修改；“如果是改成针对不同人群修改就好了” |
| 第三幕 · 守住（旧版：撤回作品） | 5 分：当地没有游客手册，能生成一份非常好 | 4 分：随时更新手册不错 | 不可能收回作品，“作废”是肯定没有的；是不断创新、更新作品，一定要换这个表述 |

三位都表示看懂了。唯一的顾虑来自文旅办主任 A：“技术是否成熟，会受网络影响吗”。我们的回答是：系统在一台电脑上离线运行，不依赖网络。

## 3. 可以匿名引用的原话

- “如果能给我一份正确的讲解词，并给观看的游客人手一本手册，对我们很有帮助。”——某非遗土陶手艺人
- “每场活动生成一场游客手册对非遗推广是很有必要的。”——文旅办主任
- “非遗的推广是不断的把这些文化传承下去，面对不同人群要有针对性的活动。”——文旅办主任

## 4. 结论与我们做的改动

团队决定：**产品只做小改，主要改申报材料的表述和重点。**

| 访谈发现 | 产品改动（小改） | 表述改动 |
| --- | --- | --- |
| 三位受访者都提到，讲解词来自传承人自己的经验，没有成稿，也没有核对这一步；手艺人想要一份正确的讲解词 | 新增“按要求生成讲解词”：选好讲给谁、讲多久，本地模型只依据收录的官方资料写草稿，再走原有的逐句核验。模型不可用时，载入部署时预置、同样只依据资料写成的草稿，并标明来源 | 第一幕从“纠错”扩展为“写出有出处的讲解，并逐句核对” |
| 活动调整的真实原因是对象不同，不是临时变卦；三位都只给第二幕 3 分 | 第二幕改为“因人而讲”。体验对象从 2 类扩到 5 类：普通游客、亲子家庭、青少年学生、老年人、专业爱好者。同一项非遗，换个对象，活动组合和讲解口吻一起调整 | 不再用“临时改需求”“一句话重排”作主卖点，改讲“面向不同人群的针对性传承” |
| 手艺人不会收回作品，只会不断创新、更新作品；三位都看重手册 | 第三幕改为“作品常新”。手艺人发布作品新版本后，系统找出引用旧版本的讲解卡和手册，重新核验后换成新版。“撤回”降为原创界面纹样的使用边界演示，不再进入主线故事 | 全面去掉“撤回、作废”说法，改为“更新、新版” |
| 手册是手艺人和观众之间的直接通道（团队判断，受访者未直接提出） | 游客手册新增“手艺人作品”栏，展示作品、说明和演示标价；购买由手艺人现场办理，系统不经手资金 | 手艺人从“被保护的对象”改写为“受益者与付费方之一” |
| 付费倾向：一位倾向按场次，一位不确定，一位说政府层面不好说 | 不改代码 | 商业模式改为按场次收费的服务，付费方是活动举办方和手艺人；政府采购只写作“待验证的渠道”，不写成已有意向 |
| 担心技术是否受网络影响 | 不改代码 | 突出“一台电脑离线运行、零模型调用费” |

### 不能这样写

- “三位受访者都愿意付费”：没有人做出付费承诺，按场次只是一位的倾向。
- “满意度 4 分”：3 个人的分数不能平均成满意度。
- “行业普遍没有讲解词”：只能写“3 位受访者都提到”。
- 任何受访者的真实姓名、单位或城市。

## 5. 申报材料怎么用

| 材料位置 | 用哪条 |
| --- | --- |
| 项目简表 · 项目背景 | 三位受访者都提到讲解词来自传承人经验，没有成稿和核对；活动因对象不同而调整 |
| 项目简表 · 关键指标 | 不写访谈数字；只写系统本身可复核的指标 |
| 项目说明书 · 立项依据 | 第 1 节的做法对比、第 3 节原话 |
| 项目说明书 · 应用前景 | 一年场次规模（十余场到近百场，各说各的范围）说明需求反复出现；不推算市场规模 |
| 商业计划书 · 商业模式 | 按场次付费的倾向（1 位），付费方为活动举办方与手艺人 |
| 宣传片 | 镜 6 放手艺人原话；第二、三幕改为“因人而讲”“作品常新” |
