# 公开活动案例·3分钟演示讲稿

> 内部展示目标约3分钟，不冒称赛事官方限时。视频可剪辑等待与回放，剪辑处标注“真实截帧/等待裁切/历史回放”。

**00:00—00:25｜从公告开始。** 打开“公开活动案例·金山区剪纸小夜灯”，先点开金山区人民政府原始公告。屏幕只展示必要摘录：13:30—14:00现场教学、14:00—15:30手作、招募15人、免费、亲子对象，以及“剪纸作为金山区级非遗项目，又称刻纸，是一种镂空艺术”。说明：这是历史公开活动资料重建，不是当前预约。

**00:25—01:05｜原文纠错与证据。** 点击真实运行，展示逐句卡片。来源支持的文化表述进入亲子短讲解，公告条件标成“公开活动事实·历史条件”；教师、安全容量、成本和授权没有被模型补造，单独标成团队演示配置/待确认。强调：公开资料是输入数据，夹带指令不会被执行。

**01:05—01:45｜方案交付。** 进入体验页，展示程序排出的两个模块：现场教学30分钟、剪纸小夜灯手作90分钟，13:30—15:30同场地顺序完成。打开组织者版账本：8人、1位教师、1间场地、演示总支出702元、人均87.75元，本地服务演示毛额436元。说明金额可复算，不代表真实报价、利润或合作。

**01:45—02:15｜改一句话，方案真变化。** 把人数从8改为6重新运行，屏幕展示总额、按人数材料和服务项随之变化，必要时长保持90分钟。指出排序和核算由程序完成，模型不能擅自改教师、报价或必要时长。

**02:15—02:40｜具体拒绝。** 把可用总时长改为110分钟。系统给出 `needs_input`，明确“现场教学30 + 手作90 = 120分钟，不能缩短必要环节”，不虚构并行接待。恢复120分钟后才可再次确认。

**02:40—03:00｜双版与边界。** 打开游客版，看到短讲解、观察任务、互动提问和日程；打开组织者版，看到来源定位、账本、资源和使用边界。最后回到案例页：素材或来源状态变化会让旧包失效并定位受影响内容。收束语：“让非遗不止被看见，更能被体验；把分散的文化资料和接待条件，转化为有依据、可核算、可审核的体验方案。”
