# 三分钟展示视频与讲稿

**用途**：校内答辩、团队内部展示和联系试用者。3分钟是内部目标，不是赛事官方限时。视频由真实本地运行截帧和真实导出样张剪辑，带有等待裁切和只读回放；没有把截图剪辑称为连续现场录屏。金额、服务报酬、容量和材料用量均标为演示测算。

## 录制与剪辑规则

- 录制时保留顶部“真实本地运行”状态；等待模型的部分可以剪掉，但转场字幕写“等待裁切”。
- 素材撤回片段使用历史截帧时，画面角标写“只读历史回放”；不得把回放当作新推理。
- 片尾字幕写“本地Qwen3-14B演示；经营数据为演示测算；最终交付需人工确认；资料与素材授权待核”。
- 不在视频中展示数据库路径、个人账号或未授权素材，不展示失败记录之外的内部日志。

## 现场讲述重点

评委最容易看见的不是模型名称，而是三次可观察的变化：事实从错误到有据，偏好从一句话到模块和账本，素材从可用到撤回再到双版更新。讲述“已实现”“演示测算”“待真实试用”三种状态时保持原词，不用“全国首创、零错误、已增收”等未经证明的词。
