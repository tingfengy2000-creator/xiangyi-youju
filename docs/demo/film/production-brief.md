# 宣传片制作说明（交给 Claude Code 云端会话）

你在“乡艺有据——可信非遗体验编排智能体”仓库里制作一部 3 分钟的宣传片《一刀之差》，身份是 5060 开发端。

目标：评委看完记得住，觉得有深度、贴合“智慧文旅与乡村振兴”主题，有电影感和高级感。同时它是参赛材料，**每一个事实、数字和系统画面都必须真实可查**。

## 技术路线

- **不引入新的付费服务。**尽量不加新的 npm 依赖；确需新增时，先核对许可证，并在说明里写明。
- **推荐做法**：自建一个确定性渲染器。
  - 每个镜头写成一个 HTML/CSS/SVG/Canvas 场景，提供 `seek(t)`，把画面设到第 t 秒的状态；
  - 用仓库已有的 Playwright 逐帧截图，24 fps、1920×1080；
  - 用 `ffmpeg` 合成 H.264 MP4（`-crf 18 -preset slow -pix_fmt yuv420p`），另导出 WebM。
  - 全片按 24 fps × 180 秒 = 4320 帧渲染，可以分镜头并行。
- **代码与产出位置**：
  - 渲染代码放 `scripts/film/`，入口 `scripts/film/render.cjs`；`package.json` 增加 `film:render`。
  - 中间产物放 `artifacts/film/`（已被忽略）。
  - 无旁白成片放 `docs/assets/video/xiangyi-youju-film-novo.mp4`，不超过 50 MB。带旁白的终版由 5060 混音后交给队员，不提交到公开仓库。
- **音频**：
  - **配乐**：首选用 Python（numpy、scipy）合成原创配乐：
    - 低频铺底：两三个持续音，缓慢起伏；
    - 拨弦单音：用 Karplus-Strong 模拟古琴或拨弦质感，用五声音阶；
    - 结尾弦乐铺开。
    - 节奏点对齐分镜：00:06、00:45、01:37、02:17、02:43。
  - **音效**：纸张、刀划、印章，同样用程序合成。
  - **旁白不经过你**：队员的原始录音不进公开仓库，最后一步由 5060 在本地混入。你需要交付：
    - 无旁白成片：画面、字幕、配乐和音效都在，旁白位置留空；
    - 音轨分轨：`docs/assets/film/mix/music.flac`、`sfx.flac`，48 kHz 立体声，与成片逐帧对齐；
    - 旁白时间表 `docs/assets/film/mix/vo-cues.json`：每句写 `id`、`start`（秒）、`max_seconds`（到下一个声音事件前可用的最长时长），以及该句音乐需要压低的区间。
  - 配乐在旁白区间先预留 12 dB 的压低空间：分轨里不压，5060 混音时用 `sidechaincompress` 实时压低。
- **字幕**：烧录进画面。思源黑体，1080p 下字高不小于 40 px，白字加 40% 墨绿底条。另外生成 `xiangyi-youju-film.srt`，放在成片旁边。

## 视觉要求

按剧本第二节执行：

- 只用品牌色；
- 宣纸纹理、红纸厚度和投影；
- 用刀划线做转场，全片不超过 5 次；
- 慢推慢移，每个镜头至少 2.5 秒；
- 加暗角和极轻的颗粒。

重点镜头：

- **镜 2–3（阳刻翻阴刻）**：全片的记忆点，要做到最好。
  - 用 `paper-garden.svg` 生成两版：线描版是阳刻（只留线条，其余镂空）；原图红面留白线，接近阴刻。
  - 刀光沿路径走，被走过的部分逐步“刻出”，用沿路径的 mask 动画。
  - 翻面用一次 3D 翻转，或者正负片交叉切换，二选一，以高级为准。
- **镜 13（纸条重排）**：纸条长度严格按真实分钟数成比例，数字取自 `manifest.json`。
- **真实界面镜头**：
  - 只能对静帧做推拉、裁切、虚化周边、加高亮框，**不能修改界面上的任何文字或数字**；
  - 镜 10 “阳”翻“阴”的刀线，是叠加在画面上的示意层；
  - 每个真实画面镜头的右上角都要有角标“真实本地运行画面”，示意动画镜头角标“示意动画”，字号不小于 20 px，半透明，不抢画面。

## 制作步骤（素材已齐，一次做完）

1. 搭好渲染器、字幕、配乐和音效流程。
2. **先做镜 2–3（阳刻翻阴刻）**，抽帧看过、满意了，再做其他镜头。
3. 完成纯动画镜头：1–7、13、16、19–21。
4. 真实画面镜头（8–12、14、15、17、18）：
   - 静帧用 `docs/assets/film/footage/s*.png`（2 倍图）；
   - 动态片段按 `manifest.json` 的 `marks` 从 `take.webm`（1920×1080，25 fps，104.6 秒）切取。等待段压缩到 1 秒，并标注“等待已剪短”；
   - 打字镜头（`act2-typing`，33.5–39.0 秒）保持原速。
5. 两个预留位：【访谈原话位】（镜 6）和【实测位】（镜 19）。目前都没有书面记录，按剧本中“没有时”的写法处理，并在 `docs/demo/film/progress.md` 里写明之后怎么替换。
6. 输出无旁白成片、音轨分轨和 `vo-cues.json`。在 `docs/demo/film/progress.md` 写清每个镜头的状态。

## 自查（每一步完成后都做）

- 每 2 秒抽一帧，拼成联系表（contact sheet），自己逐张看：
  - 有没有错字；
  - 文字有没有溢出或被裁切；
  - 角标对不对；
  - 色彩是否统一；
  - 画面有没有空洞或闪烁。
- 用 `ffprobe` 确认：时长 180 ± 5 秒，1920×1080，24 fps，音频 48 kHz 立体声。用 `ebur128` 确认配乐加音效的响度约 −20 LUFS，给旁白留出空间。
- 对照剧本第四节，逐条核对片中出现的每个事实和数字，确认都有出处。
- 对照剧本第六节，确认没有出现禁止的内容。
