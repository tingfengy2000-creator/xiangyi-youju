# 宣传片制作说明（交给 Claude Code 云端会话）

你在“乡艺有据——可信非遗体验编排智能体”仓库里制作一部 3 分钟的宣传片《一刀之差》，身份是 5060 开发端。

目标：评委看完记得住，觉得有深度、贴合“智慧文旅与乡村振兴”主题，有电影感和高级感。同时它是参赛材料，**每一个事实、数字和系统画面都必须真实可查**。

## 技术路线

- **不引入新的付费服务。**尽量不加新的 npm 依赖；确需新增时，先核对许可证，并在说明里写明。
- **推荐做法**：自建一个确定性渲染器。
  - 每个镜头写成一个 HTML/CSS/SVG/Canvas 场景，提供 `seek(t)`，把画面设到第 t 秒的状态；
  - 用仓库已有的 Playwright 逐帧截图，24 fps、1920×1080；
  - 用 `ffmpeg` 合成 H.264 MP4（`-crf 18 -preset slow -pix_fmt yuv420p`），另导出 WebM。
  - 全片按 24 fps × 180 秒 = 4320 帧渲染，可以分镜头并行。
- **代码与产出位置**：
  - 渲染代码放 `scripts/film/`，入口 `scripts/film/render.cjs`；`package.json` 增加 `film:render`。
  - 中间产物放 `artifacts/film/`（已被忽略）。
  - 成片两版：`docs/assets/video/xiangyi-youju-film-male.mp4` 和 `xiangyi-youju-film-female.mp4`，各不超过 50 MB。画面、字幕、配乐完全相同，只换旁白。
  - 分轨放 `docs/assets/film/mix/`：`music.flac`、`sfx.flac`、`vo-male.flac`、`vo-female.flac`（处理后、按成片时间对齐），以及 `vo-cues.json`，方便以后只改一句时重新混音。
- **音频**：
  - **配乐**：首选用 Python（numpy、scipy）合成原创配乐：
    - 低频铺底：两三个持续音，缓慢起伏；
    - 拨弦单音：用 Karplus-Strong 模拟古琴或拨弦质感，用五声音阶；
    - 结尾弦乐铺开。
    - 节奏点对齐分镜：00:06、00:45、01:37、02:17、02:43。
  - **音效**：纸张、刀划、印章，同样用程序合成。
  - **旁白（男声、女声两版，原始录音在 `docs/assets/film/voice/`，规则见 [旁白稿](voiceover.md) 的“已录制”一节）**：
    1. **切分与识别**：用开源语音识别 faster-whisper（MIT 许可，`pip install faster-whisper`，模型 `medium` 或 `large-v3`，`language="zh"`，打开 `word_timestamps`）转写全文，得到每段话的起止时间。装不上或下载不了模型时，先停下报告，不要凭静音切分去猜哪段是哪句。
    2. **对句**：录音按 VO-01 到 VO-17 顺序录。用字符编辑距离，把每段转写和 17 句原文对齐，归到对应的 VO 编号。同一句连续读的几遍归为一组。忽略标点和“的/地”等同音差异。
    3. **选遍**：每组里，先排除这些遍：字错率（CER）超过 8%、漏字或加字、中途停顿重来、开头或结尾被截断、有明显喷麦或噪音。剩下的遍里，**优先选最后一遍**（队员读到第 4 遍以上时，说明前面几遍不满意）；最后一遍若被排除，再往前找。整组都不合格时，选 CER 最低的一遍，并在选片记录里标“建议重录”。
    4. **选片记录**：写入 `docs/demo/film/vo-selection.md`，男女两版分开。每句列出：选中遍在原始文件里的起止秒数、转写文字、CER、被排除的遍及原因。队员看了不满意可以指定改用哪一遍。
    5. **处理**：剪切时前后各留 80 ms，加 10 ms 淡入淡出。处理链为 `highpass=f=80`、`afftdn`、`deesser`、轻度 `acompressor`，最后 `loudnorm=I=-16:TP=-1.5`。**不改音高和音色。**如需对齐画面，优先微调镜头时长；变速只允许 0.95–1.05 倍（`atempo`）。
    6. **混音**：旁白出现时，用 `sidechaincompress` 把配乐压低 12–15 dB。
- **字幕**：烧录进画面。思源黑体，1080p 下字高不小于 40 px，白字加 40% 墨绿底条。另外生成 `xiangyi-youju-film.srt`，放在成片旁边。

## 视觉要求

按剧本第二节执行：

- 只用品牌色；
- 宣纸纹理、红纸厚度和投影；
- 用刀划线做转场，全片不超过 5 次；
- 慢推慢移，每个镜头至少 2.5 秒；
- 加暗角和极轻的颗粒。

重点镜头：

- **镜 2–3（阳刻翻阴刻）**：全片的记忆点，要做到最好。
  - 用 `paper-garden.svg` 生成两版：线描版是阳刻（只留线条，其余镂空）；原图红面留白线，接近阴刻。
  - 刀光沿路径走，被走过的部分逐步“刻出”，用沿路径的 mask 动画。
  - 翻面用一次 3D 翻转，或者正负片交叉切换，二选一，以高级为准。
- **镜 13（纸条重排）**：纸条长度严格按真实分钟数成比例，数字取自 `manifest.json`。
- **真实界面镜头**：
  - 只能对静帧做推拉、裁切、虚化周边、加高亮框，**不能修改界面上的任何文字或数字**；
  - 镜 10 “阳”翻“阴”的刀线，是叠加在画面上的示意层；
  - 每个真实画面镜头的右上角都要有角标“真实本地运行画面”，示意动画镜头角标“示意动画”，字号不小于 20 px，半透明，不抢画面。

## 制作步骤（素材已齐，一次做完）

1. 搭好渲染器、字幕、配乐和音效流程。
2. **先做镜 2–3（阳刻翻阴刻）**，抽帧看过、满意了，再做其他镜头。
3. 完成纯动画镜头：1–7、13、16、19–21。
4. 真实画面镜头（8–12、14、15、17、18）：
   - 静帧用 `docs/assets/film/footage/s*.png`（2 倍图）；
   - 动态片段按 `manifest.json` 的 `marks` 从 `take.webm`（1920×1080，25 fps，104.6 秒）切取。等待段压缩到 1 秒，并标注“等待已剪短”；
   - 打字镜头（`act2-typing`，33.5–39.0 秒）保持原速。
5. 两个预留位：【访谈原话位】（镜 6）和【实测位】（镜 19）。目前都没有书面记录，按剧本中“没有时”的写法处理，并在 `docs/demo/film/progress.md` 里写明之后怎么替换。
6. 按上面“旁白”一节切分、选遍并处理男女两版，写好 `vo-selection.md`。
7. 输出男声、女声两版成片和分轨。在 `docs/demo/film/progress.md` 写清每个镜头的状态。

## 自查（每一步完成后都做）

- 每 2 秒抽一帧，拼成联系表（contact sheet），自己逐张看：
  - 有没有错字；
  - 文字有没有溢出或被裁切；
  - 角标对不对；
  - 色彩是否统一；
  - 画面有没有空洞或闪烁。
- 用 `ffprobe` 确认：时长 180 ± 5 秒，1920×1080，24 fps，音频 48 kHz 立体声。用 `ebur128` 确认两版成片的整体响度都约为 −16 LUFS，旁白清楚、盖过配乐。
- 对两版成片各跑一次语音识别，核对每句旁白都在、顺序正确、没有被截断，并且和字幕一致。
- 对照剧本第四节，逐条核对片中出现的每个事实和数字，确认都有出处。
- 对照剧本第六节，确认没有出现禁止的内容。
