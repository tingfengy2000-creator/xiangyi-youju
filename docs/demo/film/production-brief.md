# 宣传片制作说明（交给 Claude Code 云端会话）

你在“乡艺有据——可信非遗体验编排智能体”仓库里制作一部 3 分钟的宣传片《一刀之差》，身份是 5060 开发端。

目标：评委看完记得住，觉得有深度、贴合“智慧文旅与乡村振兴”主题，有电影感和高级感。同时它是参赛材料，**每一个事实、数字和系统画面都必须真实可查**。

## 先读

1. `AGENTS.md`：协作约定，必须遵守。不推送 main，不强推，不改写历史。
2. [剧本与分镜](film-script.md)：每个镜头的画面、时长、旁白编号和标签，是本片的唯一依据。
3. [旁白稿](voiceover.md)：17 句旁白和目标时长。
4. [素材清单](asset-manifest.md)：能用的素材和许可；没列在里面的素材不能用。

## 分支

- 从 `origin/dev/5060-film-plan` 新建 `dev/5060-film`（剧本、素材清单和采集脚本都在这个分支上；它基于当前验收候选，main 合入候选后两者一致），完成后普通推送。开始前先 `git merge origin/main`，有冲突就停下报告。
- 真实运行素材在分支 `dev/5090-film-footage` 的 `docs/assets/film/footage/` 下。**这个分支可能还不存在**，见下文“分两步做”。

## 技术路线

- **不引入新的付费服务。**尽量不加新的 npm 依赖；确需新增时，先核对许可证，并在说明里写明。
- **推荐做法**：自建一个确定性渲染器。
  - 每个镜头写成一个 HTML/CSS/SVG/Canvas 场景，提供 `seek(t)`，把画面设到第 t 秒的状态；
  - 用仓库已有的 Playwright 逐帧截图，24 fps、1920×1080；
  - 用 `ffmpeg` 合成 H.264 MP4（`-crf 18 -preset slow -pix_fmt yuv420p`），另导出 WebM。
  - 全片按 24 fps × 180 秒 = 4320 帧渲染，可以分镜头并行。
- **代码与产出位置**：
  - 渲染代码放 `scripts/film/`，入口 `scripts/film/render.cjs`；`package.json` 增加 `film:render`。
  - 中间产物放 `artifacts/film/`（已被忽略）。
  - 成片放 `docs/assets/video/xiangyi-youju-film.mp4` 和 `.webm`，单个文件不超过 50 MB。
- **音频**：
  - **配乐**：首选用 Python（numpy、scipy）合成原创配乐：
    - 低频铺底：两三个持续音，缓慢起伏；
    - 拨弦单音：用 Karplus-Strong 模拟古琴或拨弦质感，用五声音阶；
    - 结尾弦乐铺开。
    - 节奏点对齐分镜：00:06、00:45、01:37、02:17、02:43。
  - **音效**：纸张、刀划、印章，同样用程序合成。
  - **旁白处理**：`highpass=f=80`、`afftdn`、`deesser`、`acompressor`（轻度），最后 `loudnorm=I=-16:TP=-1.5`。
  - **混音**：旁白出现时，用 `sidechaincompress` 把配乐压低 12–15 dB。
- **字幕**：烧录进画面。思源黑体，1080p 下字高不小于 40 px，白字加 40% 墨绿底条。另外生成 `xiangyi-youju-film.srt`，放在成片旁边。

## 视觉要求

按剧本第二节执行：

- 只用品牌色；
- 宣纸纹理、红纸厚度和投影；
- 用刀划线做转场，全片不超过 5 次；
- 慢推慢移，每个镜头至少 2.5 秒；
- 加暗角和极轻的颗粒。

重点镜头：

- **镜 2–3（阳刻翻阴刻）**：全片的记忆点，要做到最好。
  - 用 `paper-garden.svg` 生成两版：线描版是阳刻（只留线条，其余镂空）；原图红面留白线，接近阴刻。
  - 刀光沿路径走，被走过的部分逐步“刻出”，用沿路径的 mask 动画。
  - 翻面用一次 3D 翻转，或者正负片交叉切换，二选一，以高级为准。
- **镜 13（纸条重排）**：纸条长度严格按真实分钟数成比例，数字取自 `manifest.json`。
- **真实界面镜头**：
  - 只能对静帧做推拉、裁切、虚化周边、加高亮框，**不能修改界面上的任何文字或数字**；
  - 镜 10 “阳”翻“阴”的刀线，是叠加在画面上的示意层；
  - 每个真实画面镜头的右上角都要有角标“真实本地运行画面”，示意动画镜头角标“示意动画”，字号不小于 20 px，半透明，不抢画面。

## 分两步做

**第一步（现在就做，不需要 5090 素材）**

1. 搭好渲染器、字幕、配乐和音效流程。
2. 完成纯动画镜头：1–7、13、16、19–21。
3. 需要真实画面的镜头（8–12、14、15、17、18），先用 `docs/assets/screenshots/` 里已提交的真实截图占位，画面左上角加大号红字“占位”。
4. 旁白还没录时，先按 `voiceover.md` 的目标时长留空，字幕照常显示，输出一个“无旁白版”。
5. 推送 `dev/5060-film`，在 `docs/demo/film/progress.md` 写清哪些镜头已完成、哪些在等素材。

**第二步（`dev/5090-film-footage` 和旁白文件都到位后）**

1. 用 `manifest.json` 的 `marks` 从 `take.webm` 切片段，替换全部“占位”。
2. 核对 `runs`，确认字幕和旁白里的数字与真实运行一致。不一致时，以运行记录为准改字幕，并在说明里列出，提醒队员重录对应的旁白句。
3. 把旁白放进片子：每句挑最好的一遍，按镜头对齐。
4. 剧本里有两个预留位：【访谈原话位】（镜 6）和【实测位】（镜 19）。只有拿到 `docs/demo/film/` 下的书面记录（访谈原话及同意引用的身份写法；耗时实测记录）才放进去；没有就按剧本的“没有时”处理。

## 自查（每一步完成后都做）

- 每 2 秒抽一帧，拼成联系表（contact sheet），自己逐张看：
  - 有没有错字；
  - 文字有没有溢出或被裁切；
  - 角标对不对；
  - 色彩是否统一；
  - 画面有没有空洞或闪烁。
- 用 `ffprobe` 确认：时长 180 ± 5 秒，1920×1080，24 fps，音频 48 kHz 立体声。用 `ebur128` 确认响度约 −16 LUFS。
- 对照剧本第四节，逐条核对片中出现的每个事实和数字，确认都有出处。
- 对照剧本第六节，确认没有出现禁止的内容。
