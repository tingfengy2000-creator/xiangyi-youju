## 与剧本的差异

1. **镜 12 不播到 `act2-click`**：录屏在 32.2–32.6 秒之间下拉框由“普通游客”变为“青少年学生”，34.2–34.8 秒页面跳到编排结果、视口整体换位。片中从 31.0 秒原速播到 34.1 秒，推近下拉框（`s10` 前后两张 2 倍图叠在同一位置，换选项的那一帧同时切换），之后停住；点击“重新编排”的瞬间不出现，结果由镜 13 的纸条接上。
2. **镜 15 警示条单独放大**：`s23` 警示条位于页面顶部，`stop-result` 时录屏视口和 `s22` 全屏截图里都看不到它。片中录屏放到结果出现后虚化，警示条 `s23` 作为一条独立静帧浮在上方并推近，不改其文字。
3. **镜 11 不再接 `s07` 下部**：新 `s06` 一屏已含三句结论。
4. **镜 7、20 不烧录字幕条**：同第一版，旁白就是画面中央逐字出现的宋体大字；SRT 完整保留。
5. **镜 6 原话写入 SRT**：原话是画面文字，不是旁白；为了字幕文件完整一并写入。
6. **镜 11b 加长到 14 秒**：VO-08b 本身 10.6 秒，后面要从生成录屏转到 `s26` 扫过 8 条核验，只按旁白定长时 `s26` 只剩约 2 秒，因此最短时长设为 14 秒。
7. **镜 18 的录屏中段**：75.8–78.9 秒之间页面从编排结果滚动到“交付”面板，片中原速保留，确认点击按 `timeline.json` 的 `events` 对齐到“拍板的，始终是人”。
8. **响度、码率、音效避让**：同第一版（逐句 `loudnorm`、`-maxrate 1800k`、音效在旁白下轻压）。

## 重新生成

```bash
npm ci
pip install numpy scipy soundfile pypinyin pillow sherpa-onnx
# 识别模型下载到 artifacts/film/models/（silero_vad.onnx、paraformer-zh-2023-09-14、sense-voice-zh-en-ja-ko-yue-2024-07-17）
python scripts/film/vo_transcribe.py female-v2-retake
python scripts/film/vo_transcribe.py female-v2-new
python scripts/film/vo_transcribe.py female-v2-yu
python scripts/film/vo_select.py female-v2-retake && python scripts/film/vo_select.py female-v2-new && python scripts/film/vo_select.py female-v2-yu
python scripts/film/vo_select.py merge       # 合并：VO-03、VO-07 取 yu；全部不合格时才用第一版女声后备
python scripts/film/vo_doc.py && python scripts/film/vo_process.py
npm run film:render                          # 时间线 → 画面 → 配乐音效 → 混音 → 成片
npm run film:verify
```

只改一句旁白时：在 `docs/demo/film/vo-overrides.json` 写 `{"female": {"VO-07": 2}}`，从 `vo_select.py merge` 往下重跑；镜头长度不变时可用 `node scripts/film/render.cjs --mux` 省去画面渲染。联系表：`node scripts/film/render.cjs --sheet 0,202,2 --cols 6`。第一版选片记录可用 `python scripts/film/vo_doc.py --v1` 重写（需要第一版的识别结果）。
