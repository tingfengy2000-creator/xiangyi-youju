## 时间线

成片 181.8 秒（要求 180 ± 5 秒）。两版旁白长度不同（男声选中句合计约 136 秒，女声约 120 秒），每个镜头取两版中较长的一句定长，两版在同一时刻开口；未对旁白变速。各镜头实际起止见 `artifacts/film/timeline.json`（`npm run film:render` 第一步生成），与剧本时间的差异如下：

## 与剧本的差异

1. **镜 13 的“茶歇”纸条**：剧本写“三条纸条（讲解、手作、茶歇）……‘茶歇’纸条被提起、移走”。真实运行 `66f40b93` 的修改前方案是“乡土入门讲解 20 分钟 + 基础剪纸手作 50 分钟”，本身不含茶歇；“不要茶歇”的作用是把“乡土茶歇”从候选模块中排除（修改前 5 个可行组合中有 2 个含茶歇，修改后为 0 个）。按“采集结果为准”，片中把茶歇画成时间轴上方标着“可选模块”的纸条，在“茶歇撤下”时被提起移走，不放进修改前的时间轴。纸条长度按真实分钟数：讲解 20、基础手作 50 → 深度手作 60、手作延伸练习 20，茶歇 20（经营配置中的最短时长）。
2. **镜 11**：剧本写 `s06` 横移扫过三句结论，但 `s06` 只截到前两句，第三句用 `s07` 下部接上。
3. **镜 17 印章时机**：剧本写印章与 VO-14 同镜；第一次成片印章声正压在“旧手册”上，识别复核听成“秀手册”，改为说完“作废”后落下。
4. **镜 7、20 不烧录字幕条**：这两镜的旁白就是画面中央逐字出现的宋体大字，再叠字幕条会重复；SRT 中仍完整保留。
5. **时长**：见上文“时间线”。
6. **旁白响度**：按制作说明逐句 `loudnorm=I=-16:TP=-1.5`。说话声峰值与响度之比较大，单纯乘增益会超出 -1.5 dBTP，ffmpeg 对几乎所有句子自动改用 loudnorm 的动态模式（缓慢增益 + 真峰值限幅）；每句实际模式记在 `artifacts/film/vo/clips.json`。只改电平，不改音色与音高，未变速。
7. **音效避让**：除配乐按要求侧链压低外，音效在旁白出现时也轻压约 4–6 dB（女声 VO-01 与刀声重叠）。
8. **码率**：成片按 `-crf 18 -preset slow` 编码，另加 `-maxrate 1800k -bufsize 3600k` 上限；不加上限时纸纹与颗粒使每版约 100 MB，超过 50 MB 限制。

## 预留位之后怎么替换

两个预留位目前都没有书面记录，按剧本“没有时”的写法处理。拿到记录后：

- **【访谈原话位】（镜 6）**：需要受访者亲口同意引用的原话与身份描述（例如“——某乡村文旅工作者”），并在 `docs/validation/` 留存访谈反馈表。替换时在 `scripts/film/stage-scenes.js` 的 `sceneCards` 中，于镜 6 时段加一张居中的宋体原话卡（复用 `typeLine`），把 `scripts/film/build_timeline.py` 中镜 6 的最短时长按原话长度加长，角标改为“访谈原话，已获同意”，然后运行 `npm run film:render`。
- **【实测位】（镜 19）**：需要同一处变更的人工耗时与系统耗时实测记录（含日期、人员、方法）。替换时在 `sceneLaptop` 的三行小字下加第四行“同一处变更：人工约 X 分钟，系统约 Y 秒（内部实测）”，角标改为“示意动画 · 实测数字见记录”，然后重新渲染。

两处都只改画面与时间线，不需要重录旁白。

## 重新生成

```bash
npm ci
pip install numpy scipy soundfile pypinyin pillow sherpa-onnx
# 识别模型下载到 artifacts/film/models/（见 scripts/film/vo_transcribe.py 文件头）
python scripts/film/vo_transcribe.py male && python scripts/film/vo_transcribe.py female
python scripts/film/vo_select.py male && python scripts/film/vo_select.py female
python scripts/film/vo_doc.py && python scripts/film/vo_process.py
npm run film:render          # 时间线 → 画面 → 配乐音效 → 混音 → 两版成片
```

只改一句旁白时：在 `docs/demo/film/vo-overrides.json` 指定遍数，从 `vo_select.py` 往下重跑；如果镜头长度不变，`node scripts/film/render.cjs --video` 可以省去。
