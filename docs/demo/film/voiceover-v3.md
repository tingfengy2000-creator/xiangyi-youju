# 宣传片旁白 · 第三版全部重录稿（女声，19 句）

上一版是分三次录的，几句之间音色不一样。这次**一次录完全部 19 句**，后期只用这一份录音。画面不改，只换旁白。

## 怎么录（一次录完，约 15 分钟）

1. **同一次、同一个地方录完**：中途不换房间、不换手机、不挪位置。衣柜前或挂窗帘的小房间，关窗、关空调和风扇。
2. **手机**：iPhone“语音备忘录”，先在 设置 → 语音备忘录 → 音频质量 里选 **“无损”**（上次 VO-03、VO-07 那份是压缩格式，这次一定要无损）。开飞行模式。
3. **距离固定**：手机放在嘴前方约 20 厘米、稍偏一点，不正对嘴。整段保持这个距离和音量，不要一会儿近一会儿远。
4. **方法**：按下表顺序，每句读 **3 遍**，遍与遍、句与句之间都停约 2 秒。读错不用停，接着把这一句重读一遍就行（读到第 4 遍说明前面不满意，后期会从最后几遍里挑）。
5. **语气**：像对一位长辈慢慢讲一件你在意的事，不播音腔。句末自然下沉，逗号处停半拍。
6. **两个读音**：“**蔚**县”读 **yù**（同“玉”）；“丰**宁**”读 níng，别读快成“丰年”。
7. **文件**：一整段录完，存成一个文件，命名 `女生旁白-全部重录.m4a`，放进 `E:\竞赛\交接\素材\旁白\第三版\`，告诉 5060 就行。
