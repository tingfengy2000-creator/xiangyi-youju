## 目标与边界

- 主项目：乡艺有据——可信非遗体验编排智能体。
- 主赛道：定向赛道“智慧文旅与乡村振兴”。
- 目标：争取进入全国决赛；前端美观大气为最高设计要求。
- 技术约束：现成模型、不微调、不新增付费 API 或软件许可费用。
- 案例：蔚县剪纸为主，丰宁满族剪纸用于地域差异对照。
- 用能智核仅保留为备选，本仓库当前不开发第二套产品。

## 本轮已落地的业务行为

1. 文化片段和经营配置分开存储；每条来源带地域、原文位置、获取时间、使用说明和版本。
2. 模型只理解、核验、表达和选择；人数、报价、教师、场地以及授权均不由模型改写。
3. 两种候选由程序核算，8人轻体验784元/90分钟，深体验1080元/120分钟；都是演示测算。
4. 最多8次模型调用、最多2轮方案修订；无解停在待补充条件，不虚构并行接待。
5. 人工确认后才可导出；来源或素材变化能定位陈述、讲解卡和方案，并撤销旧确认。
6. 三页区分真实任务、历史回放、预设案例和运行失败，进度来自服务端事件。

已通过88项后端程序/契约检查，并单独完成四个真实模型短任务、共12次本地调用。首次含冷启动37.745秒，其余2.490、2.023、2.465秒。[模型未接通失败记录](../validation/live-cases/model-unavailable.json)仍保留，是安装完成前的实际连接失败，未生成预设答案。

## 已知限制

- 暂无真实社区/传承人合作、场地经营数据或素材授权结论。
- 演示价格可计算，本地服务报酬不等于村民净利润。
- 已有少量本机时延，尚无泛化准确率、正式独立测试集或 Agent 相对强基线提升的实测结果。
- 资料只含两个官方页面的6个短片段；接待配置仅覆盖蔚县，且全部为演示。其他地域有文化资料也不等于具备接待资源。
- 使用状态变化会定位依赖并完整重跑小任务；自动网页更新、细粒度增量推理、多场次并行接待尚未实现。
- 已下载的HTML是导出时快照，不能远程抹除或自动更新；系统阻断过期任务再次导出，重新核验后应以新包替换旧文件。
- 浏览器资源与本地API有明确隔离；尚未完成整机断网与其他操作系统验收。
- 原开发排期需随实际进度调整，校内截止日期仍以学校通知为准。
