# 项目进度

最后更新：**2026-09-30**。这是当前状态的统一入口，状态变化时同步 README 摘要。

## 现在做到哪里

产品方案、三页交互原型与规范仓库已建立；真实模型、检索与 Agent 后端尚未实现。当前可以演示核验交互设计、实际变化的演示账本和活动约束，不能宣称任意输入已获得模型核验。

## 目标与边界

- 主项目：乡艺有据——可信非遗体验编排智能体。
- 主赛道：定向赛道“智慧文旅与乡村振兴”。
- 目标：争取进入全国决赛；前端美观大气为最高设计要求。
- 技术约束：现成模型、不微调、不新增付费 API 或软件许可费用。
- 案例：蔚县剪纸为主，丰宁满族剪纸用于地域差异对照。
- 用能智核仅保留为备选，本仓库当前不开发第二套产品。

## 下一步：最小真实闭环

1. 建立带地域、来源、日期和使用范围的资料清单。
2. 配置本地模型环境，记录模型版本与推理设置。
3. 完成“用户文案 → 拆分事实 → 检索资料 → 带引用结果”。

以上为后续计划；本次建立仓库不等于已经安装模型或完成这些工作。
