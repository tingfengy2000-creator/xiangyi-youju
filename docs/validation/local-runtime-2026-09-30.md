# 2026-09-30 本地最小业务闭环实测

本轮核心API验收已在本机完成 **4 个短任务、12 次真实本地模型调用**，贯通地域事实核验、演示方案计算、预算变化修订和素材撤回后的重新核验。另有4个浏览器任务、16次调用，详见第7节；合计8个真实推理任务、28次调用，不含安装前的1次连接失败。无解任务按预期停在“需要补充条件”，没有强行生成接待方案。

这是一轮小规模工程验收，不是泛化准确率测试、竞赛成绩预测或真实经营成效评估。全部价格、人员、场地和服务报酬仍为演示配置。自动化验收调用了负责人确认接口以检查流程；不表示文化专家、场地方或经营者已经审核或授权。

## 5. 素材撤回、确认与双版导出

[素材影响记录](live-cases/material-impact.json)显示 `mat-paper-garden` 从可用版本 1 变为已撤回版本 2。预算任务中的 `card-c1`、`card-c2` 和轻体验方案被定位为受影响内容；旧确认失效，验收脚本确认旧包导出返回 HTTP 409。

随后生成的新任务 `material-refreshed` 保留 `parent_id`，指向原预算任务；新记录的 `material_versions` 为空，两张卡片的 `material_ids` 也为空。新的游客版保留有来源的文化内容，但不再嵌入原装饰纹样。验收结束后脚本将演示素材恢复可用，汇总记录为 `material_restored=true`；恢复不抹去撤回记录，也不自动恢复旧确认。

本轮已生成地域纠错、预算修订、撤回后刷新三组游客版与组织者版 HTML。对这些本地原始导出文件核对后确认：文字与对应卡片一致，预算和日程与程序结果一致，组织者版含确认时间和版本，撤回后的两版均不含该纹样。报告中的“确认”指验收脚本走通显式确认接口，不声称已获得实际经营或文化使用授权。

**归档时间点说明：**本目录的 4 个任务 JSON 是脚本在工作流结束、调用确认接口之前保存的原始快照，因此 `approval=null`，状态仍是 `awaiting_review` 或 `needs_input`。它们不是最终确认状态截图；没有为美化结果补写 `approval`。确认与导出步骤由验收脚本断言、汇总结果及本机原始 HTML 对照验证。素材影响记录还列出了先前模型不可用的历史任务，不把该任务计入本轮 4 个任务或 12 次成功调用。
