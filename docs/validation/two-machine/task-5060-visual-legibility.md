## 目标

三页里有大量 8–11px 的中文说明、标签和账目注释。手机端的媒体查询还会再缩小，最小到 8px。投屏答辩和手机查看时，这些字很难看清。本任务只提高可读性，不改布局结构、配色、文案、业务逻辑或后端导出。

## 改动

1. 中文文字字号下限设为 12px：155 处样式声明中，含中文的提到 12px。
2. 纯拉丁字母的装饰性小标签（`eyebrow`、品牌英文副标题、`CULTURE ATLAS` 编号等）下限设为 10px，保留大字距的版式感。
3. `h1–h3` 加 `text-wrap: balance`，避免手机端标题末行只剩一个字（例如“处。”单独成行）。
