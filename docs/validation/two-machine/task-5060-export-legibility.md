## 目标

导出体验包里有 13 处字号小于 12px：页眉版本标记、封面图注、指标说明、讲解卡页脚、来源标签、组织者账目表（手机端 10px）、页脚等，最小只有 9px。这些字号屏幕阅读吃力，打印出来也偏小。本任务把它们统一提到 12px。只改 CSS 字号，不改导出内容、账目计算、确认和失效门禁。

## 改动

1. `CSS` 中所有小于 12px 的 `font-size` 提到 12px，共 13 处，包括手机端账目表。
2. 保留打印模式正文基准 `@media print{body{font-size:11px}}`，以免 A4 页数增加。
3. 新增回归测试：导出 CSS 中除打印正文基准外，不允许出现小于 12px 的字号。
