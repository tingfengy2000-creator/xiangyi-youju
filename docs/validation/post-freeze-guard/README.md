# 冻结后审计：禁止未修改的失败原句重新投票

这是一项在24条新输入首跑完成后的程序审计补丁，不修改新输入、SH-22时长范围规则、提示词、经营配置或排序。首跑仍对应[原实现冻结](../semantic-cases/implementation-freeze.json)，不能把其结果称为本补丁版本的24例实测。

## 发现与修复

原程序禁止对明确`unsupported`/`insufficient`的教学直接重新扫描，但重新生成分支没有确认失败原文真的改变。模型若原样重发候选，再次扫描改判支持，就可能把同一句失败内容重新投票放行。

本补丁只在重新生成教学后、扫描前增加一道程序门禁：旧扫描明确不支持、信息不足，或`activity_scope_passed=false`的原文，如果仍出现在新候选任意单元，立即保留失败，不再次扫描。比较按NFKC统一全半角并忽略空白、标点和零宽格式；移动条目、改另一句、原句外加文字都不能解禁。不依赖原条目编号保持不变。

真正移除或改写原句后仍须完整扫描，程序不会直接判支持。此门禁防止原文和简单形式变化的重复判定；它不声称解决任意同义改写的文化语义问题，新的表达仍受现有事实、来源、活动边界及人工确认检查约束。

## 程序验证

完整后端检查：210项通过，4.55秒。新增11项覆盖原样重发、三种明确拒绝状态、改另一句、移位、空白/中英文标点/零宽字符、包含原句、真正修改、移除越界活动，以及修订后扫描仍明确不支持时继续阻断。使用假模型检验门禁，不算真实推理效果。

记录见[test-results.json](test-results.json)，原/新源码与测试文件哈希见[patch-manifest.json](patch-manifest.json)。补丁后旧六例已另行完成[真实回归](../semantic-regression/audit-regression/summary.json)：6/6通过，26次真实调用，三条完整交付均完成双版导出、一条必要确认、两条正确拒绝，任务耗时1.615—11.822秒。这是已用于开发的回归输入，不是新的验收成绩；未覆盖或复跑新24例首跑。
