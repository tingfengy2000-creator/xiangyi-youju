# 乡艺有据——可信非遗体验编排智能体

版本：设计稿 V1，2026-09-29。主赛道：定向—智慧文旅与乡村振兴。主目标：提高进入全国决赛的竞争力。最高设计要求：前端美观大气，且关键画面能对应真实功能与证据。

## 1. 把评审要看的内容做进产品

产品为乡村文化志愿者、小型研学组织者、非遗体验经营者，将分散文化资料变成**有出处、可执行、可解释收益与接待边界的非遗体验包**。

一句话说明：**让乡土故事有据可查，让体验安排能够执行，让本地服务价值清楚可见。**

核心闭环：地域资料与使用边界 → 事实查证 → 讲解与体验编排 → 时间/容量/预算/文化限制校验 → 人工确认体验包 → 编辑与使用反馈。

本届文旅方向明确涉及非遗数字活化、智能导览、乡土文化传承以及经济和生态价值。我们的业务机制应逐项回应这些关注点。[赛题正文](https://cpipc.acge.org.cn/cw/getContestWebsiteQuestionById?questionId=3fad0367582f4eff9bfbf91868eb4779)

| 评审关注 | 产品中对应内容 | 初赛应提交的证据 |
|---|---|---|
| 创意设计 | 主动查证与最小修改；根据限制修订体验计划 | 与强固定流程的对照、完整失败修复案例 |
| 技术落地 | 现有电脑本地LLM，离线资料，确定性校验 | 可运行原型、源码、环境说明、真实运行录像 |
| 经济效益 | 内容制作/复核时间；可核算的体验成本 | 操作计时与场景试算，明确假设 |
| 村民增收 | 手艺教学、村民讲解、茶歇等本地付费服务项 | 透明收款项目与后续试用计划；不虚构已增收 |
| 生态保护 | 小组接待上限、材料复用、禁入/禁采集规则 | 已配置规则的违规检出与方案修订 |
| 乡土传承 | 地域与版本分开，出处保留，讲述者署名和使用限制 | 地域混淆测试、来源卡、署名/禁公开机制 |
| 可持续发展 | 资料更新、社区纠错、模板复用、本地低运行费用 | 更新记录、版本回滚、复制到第二案例的过程 |

初赛是专家网络评审，考察创新、完成程度、性能、应用价值和材料规范。要进决赛，美观界面必须通过截图与连续演示进入申报材料，同时有可运行系统和实测结果支撑。[官方邀请函](https://cpipc.acge.org.cn/cw/contestNews/detail/1/2c9080189ef4ecee019f036d22cf5bcb?page=0)

## 2. 首版范围

主案例为**蔚县剪纸文化资料与乡村研学体验场景**。县域文化事实和具体村落经营数据分别管理，不把县域特点无依据地归给某家商户、某位手艺人。

首版做一个主专题、三组精修演示、一个主要体验包模板。丰宁满族剪纸用作地域事实对照。真实营业信息、场地、报价与人员授权暂无合作输入，因此先采用明确标识的演示经营配置。

交付体验包包括：

- 带来源的讲解卡，可按儿童/成人和篇幅调整。
- 活动日程与任务单。
- 人数、时间、费用和文化使用限制的校验结果。
- 材料、组织、本地服务支出的明细。
- 待人工确认项、资料版本、使用边界与署名。

首版以三页组织：乡土发现、可信内容工坊、体验与共益。手机端沿用同一套响应式界面。支付、真实预订、全国景区地图、VR、数字人和多租户后台不进入当前开发范围。

## 3. 前端美观大气的具体标准

采用当代文化展陈的版式：纸白底、深墨绿大色块、朱砂强调、少量暖金，标题用系统衬线中文字体，操作文字用清晰的无衬线字体。大量留白和规整对齐，避免把所有内容塞成数据大屏。

视觉关键词：**文化感、编辑感、可信感、留白、层次**。原创抽象剪纸纹样承担品牌主视觉，清楚标明设计用途；没有授权的传统实物照片不冒充原创素材。

| 页面 | 首屏重点 | 核心交互 | 设计验收 |
|---|---|---|---|
| 乡土发现 | 大幅文化主视觉、简洁主张、两个明确入口 | 进入审校或体验编排 | 一眼看懂服务什么、有什么特色 |
| 可信内容工坊 | 原稿/问题/证据/修订清楚对应 | 定位来源、逐项确认修改、导出讲解卡 | 不用长聊天记录承担主要界面 |
| 体验与共益 | 左侧条件，右侧日程与费用流向 | 调整人数预算时长、查看冲突、导出体验包 | 数值联动正确，假设与真实信息可辨 |

统一交互规则：主要动作突出；错误、未知、冲突和通过均有文字标签；有加载、空结果、失败与回放状态；不使用虚构的模型思考动画。用户看到的是任务进度和工具证据，不是模型内部思维链。

当前已做的本地原型：[交互原型](../../frontend/prototype/index.html)。其中核验为只读预设稿及预置结果，避免让任意输入得到同一套假结果。正式系统接入模型后才能支持任意文稿。

## 4. 三组精修案例

### 案例A：同名非遗，不能串用地域事实

测试输入在蔚县剪纸讲解中故意写入“阳刻为主”。官方蔚县条目支持阴刻占主要地位，丰宁条目提供不同地域的对照。界面定位句子、展示来源、提出最小修改；正确内容保持不变。[蔚县官方条目](https://www.ihchina.cn/project_details/20184.html)｜[丰宁官方条目](https://www.ihchina.cn/project_details/20183.html)

演示强调：这是人为植入错误的测试稿，尚不能证明现实运营稿件的错误发生率。模型判断的是“所引来源是否支持这句话”，不是评价哪种文化版本最正宗。

附加两类小案例：用户只说“剪纸”时先澄清地域；没有有效来源的当日开放/预约信息标记待确认。最终输出具有来源卡的文化讲解，而不是到处带着警告符号的原始技术报告。

### 案例B：能生成的行程，不一定能接待

输入人数、时长、预算和可用场地。读取经营者配置后发现人数超上限、时间不足或费用超预算，程序返回具体冲突；Agent解释并提出需要用户确认的调整，不偷偷改变人数、报价或文化限制。

当前视觉原型采用固定120分钟日程：讲解30分钟、手作60分钟、茶歇30分钟，点位之间假设位于同一演示场地、无额外移动时间。默认可用窗口150分钟、8人、容量12人、人均预算160元。

冲突按钮改为16人、容量8人、预算60元/人、窗口90分钟，应显示不可行。正式Agent可提出减少人数、延长时间或请求新的场次配置，但未得到资源数据前不能假设可并行开课。

### 案例C：把文化体验与本地服务报酬联系起来

演示账本假设如下，全部可以在经营配置中改动：

| 项目 | 计算方式 | 默认8人 |
|---|---|---:|
| 村民讲解服务 | 固定300元 | 300 |
| 手作指导服务 | 35元×人数 | 280 |
| 本地茶歇服务 | 20元×人数 | 160 |
| 工具与材料 | 固定100元＋10元×人数（复用选项） | 180 |
| 组织成本 | 固定160元 | 160 |
| 总支出 | 上述合计 | **1080** |

本地三项服务毛收入合计740元，占总支出的68.5%；人均135元。它不是村民净利润，也不是已经实现的增收。材料成本是否支付给本地商户、税费交通等均没有证据，当前不计入“已实现本地收益”。

另设合法的轻体验方案：20分钟讲解、50分钟手作、20分钟茶歇；讲解200元，手作25元/人，茶歇15元/人，工具80元、复用耗材8元/人、组织120元。8人总784元，本地服务520元，人均98元。在默认预算和时间内，两种方案都可行，用户可比较学习时长、预算、本地服务支出与演示纸材数量。由此展示具体取舍，不将花钱更多简单等同于更公平或更生态。

关闭复用选项时，示例耗材改为16元/人；8人总支出为1128元，12人总支出为1412元。当前原型把复用设为演示活动要求，关闭会提示规则不满足。真实项目需采用经营者确认的配置，不能将此示例当作法规。

生态展示使用“材料数量/复用安排/超限人数/禁入规则”等可查项目；没有实测排放因子，不输出减碳吨数。接待上限是运营配置，不冒称经科学测定的生态承载力。

## 5. LLM与Agent的价值边界

LLM承担语言和语义工作：理解受众与模糊需求、拆分可核对事实、选择查询、发现来源差异、按证据改写、解释方案取舍。Agent根据任务状态选择下一步，协调检索、校验、计划和修订。

程序承担精确工作：地区标识、引用ID存在性、金额、人数、时长、容量、禁止事项、预算和状态保存。文化使用授权、公开发布与实际经营决定交给人。

首版一个有状态主Agent即可；核验、讲解和计划是不同职责与提示模板，可共用一个模型并顺序执行。没有必要让多个大模型相互聊天以表现“智能”。

拟验证的三点贡献：

1. **地域与来源约束下的主动查证**：根据缺口决定再查、追问或保留未知，减少地域误配。
2. **事实与体验共同校验**：讲解能溯源，同时体验安排满足实际配置的时间、预算和文化限制。
3. **可追溯的最小修改**：修正错误时保留正确内容，来源变化后只重审受影响的句子与体验卡。

上述是设计假设，不宣称算法首创或已获得提升。必须用同模型、同资料、同工具的强固定流程进行验证。

## 6. 文化保护与社区控制

为素材、讲述者和活动配置保留署名、使用范围、禁拍/禁公开、撤回与更新状态。公开名录资料和真实传承人授权分开管理；目前没有社区合作就不能标“传承人已授权”。社区反馈可以补充资料，但进入事实库前需审核并保留版本。

内部草稿可保留待确认内容；对外使用的体验包必须排除禁公开、已撤回或许可待确认的受限素材。未确认的经营条件也不得标成已授权可执行，避免让文化保护只停留在提醒文字。

不生成替代传承人的身份、声音或“正宗性评分”。创意文案与历史事实分区；事实不可无证据补全。不同社区的活态传承差异可并列展示，不强行合并成单一答案。

UNESCO的伦理原则强调社区主导、知情同意、尊重公开限制以及相关群体的精神与物质利益，可作为这些设计的依据。[UNESCO伦理原则](https://ich.unesco.org/en/ethics-and-ich-00866)

## 7. 经济与持续运营假设

参赛期工具免费、本地运行，服务于内容制作和体验试算；不做抽佣交易平台。长期可以提供一次性交付、资料维护与培训服务，或由村集体/公共文化机构自持运行。这些是待验证模式，不填写虚构营收。

村民收益路径：可信介绍降低信息混淆 → 可执行的小型体验增加本地讲解/教学服务入口 → 明示服务报价与收款角色 → 真实试用后记录订单及费用。当前只能验证内容生产效率和预算模型，未验证转化、销量或村民净增收。

持续运行依靠本地资料版本、轻量模板、来源更新提示、可撤回内容和小场景复制，不以不断增加新模型、全国数据抓取或高云成本为前提。

## 8. 进决赛的取舍

前端优先完成三个有辨识度的页面，然后把同一条真实流程打通。核心证据优先于扩展功能：一个稳定本地模型、一份认真标注的测试集、一条可运行Agent流程、三个能解释的演示故事。

漂亮界面、文稿和样例可以精修；实验结果、合作状态、经营数据与文化出处保持真实。初赛材料将界面、闭环、实验与应用价值连在一起，让评审能迅速判断“看起来完成了什么，实际又证明了什么”。
