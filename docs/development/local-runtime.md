# 本地运行与维护

本项目采用免费本地路线，不微调、不接付费 API。运行中的业务网络请求只指向本机 Ollama；依赖、官方模型和精选资料的初次准备需要联网。

双机开发请先阅读[双机开发交接入口](two-machine-handoff.md)。5060 端可以只安装锁定依赖并使用 `--api-only` 做无模型检查；5090 端负责真实本地模型、关键导出和最终集成。

## 本机启动

在仓库根目录运行：

```powershell
.venv\Scripts\python.exe scripts/start_local.py
```

浏览器打开 `http://127.0.0.1:8780/`。界面顶部会分别显示业务服务和本地模型状态；服务连接成功不代表模型已成功推理。

启动脚本只在子进程中配置环境变量，不改系统 PATH 或其他项目环境。Python 包在 `.venv/`；Ollama 独立程序、日志、运行数据库在 `artifacts/runtime/`；官方 GGUF 和 Ollama 模型存储在 `models/`。这些目录都被 Git 忽略。

Ollama 使用独立端口 `127.0.0.1:11439`，应用使用 `127.0.0.1:8780`。仅绑定本机。停止前台应用按 `Ctrl+C`；独立 Ollama 进程可能继续保留，模型在最后一次调用后空闲约15分钟卸载。日志和本项目 Ollama PID 见 `artifacts/runtime/`，不要结束其他项目的推理服务。

## 在另一台电脑准备

本轮隔离环境采用 Python 3.12。先安装可用的 Python 3.12，再在仓库根目录建立环境：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe scripts/setup_local.py
.venv\Scripts\python.exe scripts/start_local.py
```

如果电脑没有 `py` 启动器，用实际 Python 3.12 解释器路径替代第一条命令。`setup_local.py` 目前为 Windows x64 的独立运行器准备脚本，不宣称已经验证其他操作系统。

首次准备会下载官方 Ollama Windows 压缩包和约9GB的 Qwen3-14B Q4_K_M GGUF。脚本固定上游版本/修订，校验完整 SHA256，分片支持续传；只使用官网下载地址。安装、导入与临时分片需要额外磁盘空间，建议预留约40GB。没有模型下载服务或推理 API 账单，网络、电力和设备成本仍存在。

`OLLAMA_NO_CLOUD=1`、`LANGSMITH_TRACING=false`、`LANGCHAIN_TRACING_V2=false` 在本项目进程内设置。不配置追踪 Key。LangGraph 的间接依赖中包含 LangSmith SDK，但本项目不启用云追踪、远程图服务或账户。

## 两种界面模式

| 入口 | 含义 |
| --- | --- |
| 上述8780业务服务 | 实际请求 FastAPI、SQLite、LangGraph 与本地模型 |
| 双击 `frontend/prototype/index.html` | 明确标注的历史设计原型，核验为预设案例 |

HTTP 页面发现业务服务不可用时会报错；只有用户明确选择才进入预设模式。模型调用失败不会自动回退到预设结果。历史任务载入后标为“历史回放”，界面不把它当成当前新推理。

## 如何使用真实流程

1. 进入“可信内容工坊”，编辑文案、地域和需求；案例下拉框只填输入，不生成答案。
2. 进入“体验与共益”，设置人数、预算、时间、场地、教师和复用条件。报价由独立经营文件读取，不由模型编造。
3. 点击核验与编排，查看服务端真实事件。程序保留支持、矛盾、分歧、不足四类结果。
4. 对照原句、修订和证据；只有有来源支持的原句或通过复核的修订进入游客讲解卡。
5. 比较已计算的候选方案。确认当前结果后，分别导出游客版与组织者版 HTML，可离线打开或由浏览器打印。
6. 修改输入后旧结果过期，必须重算。来源或素材使用状态变化后旧确认撤销，需要重新核验。

导出文件始终标明模拟体验与演示测算，不代表真实预约、场地许可、传承人授权、净利润或已经实现的增收。

## 复现三个现场演示

**地域事实纠错。** 保持蔚县地域，使用默认文案并点击“核验并编排体验”。“以阳刻为主，阴刻为辅”应被逐句核验；修订需要再次核验。关于“每天开放、无需预约”的句子没有经营依据，应保留信息不足，不进入游客讲解。展开来源可查短引、原文位置、日期和链接。需要观察实际返回，不能只按这段操作说明宣布通过。

**模块偏好与预算变化。** 默认选择模块组合，可在文字中提出“不安排茶歇，多留手作时间”，并将表单人均预算改为110。客群等文字与表单冲突时，先选择保留表单或采纳文字；新任务读取确认后的约束，实际改变模块、手作分钟和费用。比较栏显示与上一次有效方案的差异，双版预览不代替确认。其它模块的硬性增删与跨村要求暂需澄清，不能编造新报价。

**旧套餐回归。** 选择“固定套餐”入口，保持8人、150分钟、优先深体验，先核对1080元/120分钟。预算110时总预算880元，轻体验784元/90分钟可行。两种套餐均包含茶歇；选择不要茶歇时套餐无解，不能偷偷删除环节继续沿用套餐价格。模块报价与套餐报价分别标明。所有价格和服务报酬都是演示测算。

**使用边界变化。** 已确认一个任务后，在体验页“文化使用边界”撤回原创展示素材。界面显示受影响讲解卡和方案，旧确认与导出立即失效。点击“依据最新资料重新核验”，待新的真实任务结束后再次确认；新包保留有来源的事实，去掉撤回的装饰素材。演示完可明确点击恢复可用，历史失效记录仍保留。

额外反例：点击“超容量且资源不足”，再实际运行。16人、单组容量8人、1位教师与1间场地没有可行方案；系统应解释冲突并停止，不自动增加资源或虚构并行接待。

## 数据在哪里

- `data/curated/sources.json`：文化片段及来源、地域、原文位置、时间、使用说明、哈希。
- `data/curated/materials.json`：原创展示素材及使用状态。
- `data/operating/demo-profile.json`：独立的演示报价、时长、接待资源与容量。
- `artifacts/runtime/app.sqlite3`：运行输入、真实事件、模型结构化输出、版本历史、确认和影响关系。

种子资料首次写入数据库。此后在界面修改的使用状态保存在 SQLite，不会因重启恢复；需要恢复时在界面明确操作。不要直接删除数据库来伪造“干净历史”。手工编辑种子文件不会覆盖既有数据库，新增专题/资料版本需另做受控迁移。

## 验证

```powershell
.venv\Scripts\python.exe scripts/check_repository.py
.venv\Scripts\python.exe -m pytest tests/backend -q
$env:BROWSER_CHANNEL = "msedge"
npm test
```

后端单元测试中的假模型只验证程序契约，不作为真实模型效果。真实模型准备好后运行小规模验收：

```powershell
.venv\Scripts\python.exe scripts/verify_live.py
$env:LIVE_BASE_URL = "http://127.0.0.1:8780"
node tests/e2e/live-workflow.spec.cjs
```

继续在浏览器里复现预算110与素材撤回两个场景，可使用刚完成的任务编号：

```powershell
$env:LIVE_CASES_ONLY_FROM = (Get-Content artifacts/live-browser-check/run.json -Raw | ConvertFrom-Json).id
node tests/e2e/live-workflow.spec.cjs
Remove-Item Env:LIVE_CASES_ONLY_FROM
```

这个入口会新建真实任务，修改本地演示素材状态并在结束时恢复；不是静态截图测试。仅检查已有最终HTML可设置 `LIVE_EXPORT_PREVIEW_ONLY=1`，此模式不调用模型或业务API，完成后清除该环境变量，避免下一次误选检查模式。

真实验收会创建运行历史、测试确认和导出，并演示素材撤回后重新核验；脚本在结束时恢复素材的可用状态，但不会抹除失效历史。全部原始输出进入 `artifacts/`，经检查后再精选归档。

## 当前能力边界

资料库仅覆盖两个剪纸地域的少量精选事实；只有蔚县演示接待配置。没有检索到不代表事实错误，未知地域或经营数据不足不会虚构答案。提示词与引用校验可降低误用，但不能代替文化专家审核。

来源变化后的刷新目前重新执行这个小任务的完整流程；已经能定位依赖关系，但没有宣称实现大型资料库的精细增量推理或取得相对基线优势。
