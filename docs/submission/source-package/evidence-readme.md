# 运行记录与样例

本目录收录作品在本地真实大模型上运行产生的原始记录，供核查系统的真实性与完整性。记录均由系统自动写出，未经人工改动。

## 真实运行记录（`真实运行记录/`）

同一场蔚县剪纸体验的五次真实运行，模型为本地部署的 Qwen3-14B（Q4_K_M），每条记录包含输入、各步骤模型输出、核验结论、方案、账目、模型调用次数与耗时。

| 文件 | 内容 | 关键结果 |
| --- | --- | --- |
| `01-讲对-讲解逐句核验` | 三句待核验讲解 | “蔚县剪纸以阳刻为主”判为与来源矛盾，修订为“以阴刻为主”；“善于多色点染”获来源支持；“每天开放并且无需预约”判为信息不足 |
| `02-因人而讲-换成青少年学生` | 体验对象由普通游客换成青少年学生 | 活动 2→4 个环节，手作 50→80 分钟，全程 70→115 分钟；874 元中本地服务报酬 584 元、材料 200 元、组织 90 元（演示测算）；面向学生的教学内容通过逐项扫描 |
| `03-作品常新-新作发布后重新核验` | 手艺人发布“花卉窗花”第 2 版后重新核验 | 引用旧版的运行被标为待更新；新运行使用作品第 2 版 |
| `04-按要求生成讲解词后核验` | 本地模型按“青少年学生、5 分钟”写成的讲解词草稿 | 8 条陈述中 7 条获来源支持，1 条（“让作品更生动。”）如实标为信息不足 |
| `05-未配置服务停下询问` | 文字需求“需要安排英语讲解” | 系统停止编排并请使用者澄清，不虚构服务 |

## 手册样例（`手册样例/`）

由第 3 条运行记录经系统导出程序生成的游客版与组织者版手册（预览稿），可直接用浏览器打开或打印。正式导出须在系统中经人工确认。

## 内部对照实验（`内部对照实验/`）

24 项预先冻结的任务，分别由智能体工作流与同模型、同资料、同工具的固定流程各运行一次，比较完整交付、必要确认与具体拒绝三类结果。`comparison-protocol.md` 为实验方案，`results.md` 为结果说明，`对照实验输入-24项任务.json` 为输入，`首次运行原始记录/` 为全部原始输出（含 `summary.json` 汇总）。该实验为团队内部验收，不是第三方检测。

文中金额、报酬、教师、场地、作品与标价均为演示配置；文化资料来自中国非物质文化遗产网等官方公开资料。
