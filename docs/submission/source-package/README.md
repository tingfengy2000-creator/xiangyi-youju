# 乡艺有据——可信非遗体验编排智能体

本目录为作品完整源代码，可在一台 Windows 电脑上离线部署运行。详细的环境、依赖、大模型部署与使用方法见上一级目录的《源码运行说明》。

## 快速开始（Windows 10/11 x64）

1. 安装 Python 3.12（64 位）。
2. 双击 `部署.bat`：创建虚拟环境、安装依赖，并下载、校验本地推理运行时与大模型（约 10 GB）。
3. 双击 `启动.bat`：启动系统，浏览器访问 `http://127.0.0.1:8780/`。

未部署大模型时，可双击 `界面原型.bat` 查看界面原型（预设案例，界面中明确标注）。

## 目录

| 路径 | 内容 |
| --- | --- |
| `backend/` | 业务服务：资料检索、逐句核验、约束编排、分众教学、版本联动、手册导出 |
| `frontend/prototype/` | 浏览器界面（乡土发现、可信内容工坊、体验与共益） |
| `data/` | 官方文化资料摘录、演示素材与作品、演示经营配置、部署预置讲解词 |
| `scripts/` | 部署脚本 `setup_local.py`、启动脚本 `start_local.py`、真实模型小规模检查 `verify_live.py` |
| `tests/` | 后端自动化测试、浏览器端到端测试、对照实验输入 |

## 测试

```bat
.venv\Scripts\python.exe -m pytest tests/backend -q
npm ci
npm test
```
