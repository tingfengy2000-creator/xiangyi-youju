# 乡艺有据小规模试用说明

这份说明面向乡村工坊负责人、研学组织者和文旅活动策划人员。试用目标是请你用一段真实但已获允许使用的剪纸讲解文案，观察系统是否能帮助你发现地域事实问题、把需求落实到活动组合，并在素材状态变化后更新体验包。试用不要求下单，也不代表合作、背书或正式评测。

## 试用前准备

请准备以下材料：

- 一个明确的地域和非遗项目，例如“河北省蔚县 / 剪纸”；
- 一段可公开或已获授权使用的讲解文案，保留原始出处；
- 一组演示接待条件：人数、每人预算、全程可用时间、开始时间、教师和场地数量；
- 一条活动偏好，例如“不要茶歇，多留手作时间”；
- 若测试素材撤回，请使用一张明确允许在本机演示的图片或素材记录。

本仓库当前经营配置是演示数据。报价、服务报酬、材料用量和容量不能直接用于真实售卖，不能据此宣称增收或安全合规。文化事实仍需当地文化人员核对。

## 建议流程（约15分钟）

1. 在“可信内容工坊”输入地域、项目和讲解文案，查看原文、修订和来源定位。特别留意文化事实、经营承诺、用户需求是否分开。
2. 在“体验与共益”输入8人、每人110元、全程上限110分钟，并写“不要茶歇，多留手作时间”。比较活动模块、手作时长、总时长、总额、本地服务报酬和纸材份数。已保存的演示变化是手作50→80分钟、全程90→100分钟、总额720→796元。
3. 先看游客版和组织者版草稿，再勾选人工确认。游客版用于阅读体验，组织者版用于核对日程、资源、账本、来源和素材边界。
4. 将一项演示素材标记为撤回，确认旧结果失效；重新核验并重新确认，检查两版体验包是否不再使用该素材。
5. 输入16人、单组容量8、教师1人，观察系统是否给出“人数16超过容量8”和“至少需要2位教师”等具体冲突，并停止确认与导出。

## 请反馈什么

请用事实描述，不需要评价模型“聪明”与否：

- 哪一句文案被误解，原文是什么，系统显示了什么；
- 来源定位是否能让你在一分钟内找到原文；
- 预算、偏好、手作时间或总时长改变后，活动是否真的改变；
- 账目中的讲解、手作、茶歇、材料、组织费用是否符合你的核对方式；
- 哪些条件必须由人工确认；
- 撤回素材后，旧包是否容易被识别为失效；
- 你愿意为资料整理、模块配置或维护支付哪一种服务费（可填“不确定”）。

请不要提供游客身份证号、电话号码、未授权图片、订单或其他私人资料。若希望我们保留反馈，请同时说明可以保存的范围和期限。
